# 布局

## 网格

- 桌面端 12 列，列间距 24px，页面边距 40px。
- 平板 8 列，列间距 16px，边距 24px。
- 手机 4 列，列间距 16px，边距 16px。

## 应用框架

左侧导航 240px，内容区最大宽度 1200px。导航在 720px 以下收起为顶部菜单。

## 间距节奏

| 关系 | token |
| --- | --- |
| 图标与文字 | `space-1` |
| 同组控件 | `space-2` |
| 卡片内边距 | `space-4` |
| 卡片之间 | `space-5` |
| 区块之间 | `space-8` |
