# Pine 设计系统

Pine 是一款面向小团队的项目协作工具。品牌气质是**安静、可靠、有条理**：界面大面积使用中性色，松绿色只留给最重要的操作和选中状态，让团队把注意力放在任务本身。

## 设计原则

- **先任务，后装饰**：每个元素都要说明它帮用户完成了什么。
- **一屏一个重点**：每屏只有一个 primary 按钮。
- **状态一眼可辨**：完成、风险、阻塞的颜色在全产品保持一致，并始终配文字。

## 如何使用

颜色是语义 token（`surface`、`ink`、`accent` 等），有浅色和深色两套主题，第一套为默认值。文字只用一个无衬线字族，分 Display、Heading、Body 三组。间距以 4 为基数，圆角控件 6–10px、容器 14–20px。

组件在 `components/bundle.js` 中以 `window.Pine` 提供，依赖 React 18。图标通过 `Pine.Icon` 按名字使用，取自 Lucide，描边 1.5。
