# Pine 设计系统

Pine 是一款面向小团队的项目协作工具。品牌气质是**安静、可靠、有条理**：界面大面积使用中性色，松绿色只留给最重要的操作和选中状态。

## 设计原则

- **先任务，后装饰**：每个元素都要说明它帮用户完成了什么。
- **一屏一个重点**：每屏只有一个 primary 按钮。
- **状态一眼可辨**：完成、风险、阻塞的颜色在全产品保持一致，并始终配文字。

## 状态色

| 状态 | token | 用法 |
| --- | --- | --- |
| 完成 | `success` | 任务完成、检查通过 |
| 风险 | `warning` | 需要注意但不阻塞 |
| 阻塞 | `danger` | 错误和破坏性操作 |

## 如何使用

组件在 `components/bundle.js` 中以 `window.Pine` 提供，依赖 React 18。

```js
const { Button, Badge } = window.Pine;
h(Button, { variant: 'primary' }, '创建任务');
```
