MineDesign 0.1.2 将生产安装改为空白工作区，移除 npm 安装包中的演示数据。

## 安装或更新

```sh
npm install --global @vontean/minedesign@0.1.2
mdn plugin install
```

需要 Node.js 22.18 或以上。新安装默认创建空的 `~/MineDesign`，不再附带或自动打开 Pine、Mine Studio 等演示作品。示例继续保留在源码的 Dev 环境中。

更新不会覆盖或删除已有用户作品。旧安装已经复制到用户工作区的文件属于用户数据，需核对内容后自行清理；本版不会静默删除可能已被编辑的项目。

仓库现已公开；生产分支通过 PR 和自动验证合入，npm 发布附源码 provenance。安装包仍附 FORK.md 的完整来源及免费、非商业分发许可。
