MineDesign 的第一个生产版本：在 Codex 聊天里生成设计稿，在侧栏查看、编辑和评论，并复用已有的设计系统。

## 安装

需要 Node.js 22.18 或以上。

```sh
npm install --global @vontean/minedesign
mdn plugin install
```

`mdn plugin install` 把 MineDesign 登记为 Codex 插件，作品默认放在 `~/MineDesign`（首次安装带上示例作品）；用 `--workspace /path` 换成别的目录，之后的更新会沿用它。评论、设置等本机数据在 `~/.minedesign`。之后在 About 里点「检查更新」即可升级到 npm 上的最新版本。

## 这一版有什么

- **设计稿与设计系统**：多画板设计稿、设计系统的颜色、文字、间距、圆角、阴影、组件与素材，都存成本地文件，可做结构检查、导入真实图片与字体。
- **Codex 原生外观**：外壳与编辑器沿用 Codex 的颜色、图标、菜单和弹窗；明暗跟随 Codex，画布为页面白色。
- **项目与文件**：顶栏的项目菜单与文件标签；设计稿和它引用的设计系统自动归为一个项目，也可用 `project.json` 明确分组。
- **编辑**：工具栏在画布底部居中，Frame 快捷键为 F；右侧面板为属性、调整、评论三个标签，代码并入属性面板，与 Debug 一样可折叠。
- **便签**：Excalidraw 式的扁平外观；改宽高时文字重新换行，便签随文字长高，不再截断。
- **评论**：与 Codex 原生评论一致——蓝色目标描边与浅蓝覆盖，点中后在落点旁浮出输入框，Enter 提交、Esc 取消；整理好的评论显式发回当前聊天。
- **About**：版本与一键更新、中英文界面切换、联系方式。

## 已知限制

- 发送评论后由 Agent 修改原稿的完整闭环、独立全页面和导出下载仍在验收中，详见仓库的 `docs/verification.md`。
- 设计系统编辑器的评论样式尚未对齐 Codex。
- 按原始许可免费、非商业分发；来源、完整许可与修改说明见包内 `FORK.md`。
