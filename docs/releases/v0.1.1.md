MineDesign 0.1.1 完善中英文界面，并调整画布、属性面板和评论操作；本版首次通过 npm 提供安装与更新。

## 安装或更新

需要 Node.js 22.18 或以上。

```sh
npm install --global @vontean/minedesign@0.1.1
mdn plugin install
```

已有 npm 安装也可以在 About 中检查更新。插件安装沿用已配置的作品目录；用户作品、评论和本机设置不因升级而重建。

## 这一版有什么

- **中英文界面**：外壳、画布、属性、设计系统、反馈和错误提示共用语言偏好；在 About 中选择中文、English 或跟随 Codex。切换时保留选中对象与评论草稿；作品文字、文件名、变量名和作者提供的标题保持原样。
- **文案维护**：按功能拆分词典，提供 CSV 导出；发布前检查词条、参数和明确界面位置的硬编码。运行时错误通过稳定错误码显示用户提示，原始详情保留用于排查。
- **画布与面板**：网点纸背景、底部胶囊工具栏、顶部缩放与撤销重做、项目文件标签，以及更紧凑的属性字段。菜单和提示气泡沿用 Codex 风格。
- **评论与加载**：统一评论标记及输入浮层，改善空输入取消与有内容草稿保留；打开和切换作品时显示对应布局的加载骨架。
- **可靠构建**：只修改共用词典也会触发编辑器重建，避免安装包仍显示旧文案。

## 发布与验证

GitHub Action 完成构建、模块和服务测试、文案检查、打包审计及隔离安装检查后，发布同一安装包到 npm 和 GitHub Release。Release 附安装包与 SHA-256 校验文件；公共 npm registry 的版本、latest 和包完整性也会核对。

中英切换、选中图层与草稿保留、错误态及重新载入已在本地浏览器验证。Codex 宿主里的完整 Agent 修改闭环、独立全页面与导出下载仍需单独验收，不能以浏览器验证代替。按原始许可免费、非商业分发，完整来源与许可见包内 FORK.md。
