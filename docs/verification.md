## 当前宿主断连与后端热更新（2026-10-25）

用户截图的 “Couldn't display MineDesign” 已在桌面日志复现：入口 minedesign_open 返回 Transport closed，宿主尚未进入插件外壳。退出旧 stdio 进程后，CLI 重装不会替当前聊天重建连接；继续点 Try again 只会重试已关闭的通道。此问题与作品 grant 404 分开判断。

已补充独立 backend 构建与稳定 runtime 门面，minedesign_reload / MCP 进程 SIGHUP 只替换后端，不结束 MCP stdio；重新打开已有作品并保留持久化批注，加载新模块失败时旧服务仍可用。安装指纹覆盖后端、外壳与两套编辑器产物。新增真实 stdio 回归验证同一个 client 在更新前后均可调用工具、读取资源和加载编辑器；插件测试现在 11/11 通过。文件与宿主模块测试 244/244，25 组服务响应差分仍通过。

最终 tarball 在隔离目录安装生产依赖后，发现 11 个工具、4 个示例，同一连接中更新成功，两类编辑器均 HTTP 200。官方 CLI 重装完成，安装路径与当前构建已核对。

**当前会话尚未恢复：** 本聊天原 stdio 连接已经关闭，实际工具仍返回 Transport closed；侧栏 DOM 显示中央加载失败，独立页面显示宿主错误。现有 CLI 与应用工具没有重连当前聊天的入口，计算机工具也不允许操作 Codex 主窗口。需要宿主在插件设置刷新 MineDesign 连接后，再验证真实侧栏与独立页面；不能把隔离安装通过写成当前聊天已经修复。今后后端更新使用 reload；改变 MCP 接口或稳定入口仍需宿主重连。

### Side panel 404 与加载状态修复（2026-10-25）

宿主缓存的插件页面可能携带上一次 MCP 进程签发的作品 grant，新进程不认识旧地址，因此同一份作品返回 404。外壳现在在初次加载、切换和重试时，先按稳定的作品目录及类型重新打开，取得当前访问地址，再恢复批注和加载编辑器；同时接收打开工具返回的作品列表更新。异步加载结果只应用到当前选择。

连接、加载、失败、重试及空作品统一显示在作品视窗中央，header 不再承载状态文字。状态区使用 Lucide 插图，失败时显示恢复说明与重试按钮，技术详情默认收起。编辑器就绪后状态区消失；未就绪时禁用批注和发送。切换作品先清空上一份作品的批注显示，重试同一份作品保留草稿。

已构建并通过 `npm test` 7/7，新增 App DOM 边界测试覆盖服务重启后旧 grant 返回 404、按目录重新打开、中央错误与重试加载状态、恢复后保留反馈。用户关闭并重新打开 side panel 后，真实 Codex 中已读到 Pine 五画板、设计系统正文与原有三条批注，切换期间的加载提示位于视窗中央。此项验证不包含完整反馈提交或导出验收。

已打开的旧外壳不会因重新构建自动更新。旧版“重新载入”仅重载内部编辑器；更新外壳后需关闭 MineDesign 标签并重新打开，无需重启整个 Codex 或结束 MCP 进程。

验证日期：2026-10-25；Codex / ChatGPT Desktop `26.1021.31345`，build `21828`。本轮按用户最新要求聚焦加载；编辑、保存、外部重载与新增批注未在本轮继续验收。

## 已知边界

- 本轮工具允许读取并操作 MineDesign 自身的侧栏 App，但禁止控制 Codex 主窗口；嵌套 iframe 截图、变换后的画板点击也不支持。因此独立全页面与完整手势操作需用户实际观察；两类编辑器的 DOM 内容读取不等于截图验收。
- 0.0.5 已安装，源码、安装缓存和构建指纹一致；当前桌面仍可能持有升级前的连接。CLI 移除后重装没有立即产生全页面连接重建日志；是否加载成功仍需从宿主刷新后的日志与实际界面确认。

- Codex 的 `sendMessage` 支持需要真实 GUI 验证。浏览器模式明确禁用“发送到当前聊天”。
- 虚拟来源下，画板 `x-import` JSX 需要的 Babel 仍按文件地址加载，在 Codex 中不可用；导出下载经插件页触发，Codex 是否放行下载未验证。
- 插件当前绑定本项目；不是成熟的跨项目作品库。重启 MCP 后，用户作品需重新打开。
- 继承 BaoCut 已关闭的快速编辑 sample、多人协作等状态，不额外接入独立模型服务。
- 上游界面文案多数保留英文，尚未完整汉化；首版优先保留布局和实际行为。
- 本地 token 参考 MCX 已记录快照，未重新测量当前 Codex 构建；视觉对齐仍需逐组件比较。
- 当前防重复提交仅在 App 会话内；跨窗口与超时不确定结果的严格一次性提交仍待完善。
